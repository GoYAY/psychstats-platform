# 教材 RAG 优化二版质量复核

2026 年 11 月 23 日更新。教材 RAG 用于编辑阶段准备术语页证据，为定义、操作解释和适用条件提供带页码的原文。公式、变量含义和数学条件来自已核验的外部证据卡。正式站展示编辑完成的页面。

## 从旧版到优化二版

| 功能 | 旧版的主要问题 | 优化二版的最终做法 |
| --- | --- | --- |
| 原文提取与分块 | OCR 易丢公式符号，长块混合定义、背景和条件 | 直接读取有文字层的 PDF，扫描页保留可追溯 OCR。按句切分带页码的短块，定位后按需回读同页，让解释与限定条件一起进入候选。 |
| 候选检索 | 前 8 条容易漏掉排位靠后的完整原文 | 继续用向量与关键词混合查询。按明确子问题检索，长块、短块两路各保留最多 24 条候选，并补充短块所在页。 |
| 证据组包 | 先放长块会用满预算，同页完整段落可能被短段挡掉。关键词同时出现也容易被误判为答全 | 逐要点判断原文能否直接回答，再机械核对摘录。用同一页完整段落覆盖其中的短段，在预算内优先交付能回答不同要点的材料。 |
| 来源与质量 | 教材缺项、OCR 信息损失和教材表述问题需要按不同原因处理 | 教材负责文字解释和适用条件，公式走外部证据卡。长块、短块和扩展文字共同执行已登记问题过滤，保留文档与页码便于回查。 |

## 旧版与优化二版的离线对照

8 个术语共设计 24 道明确文字题与 5 道公式题。22 项教材主责及共同负责的文字要求计入教材指标。两版共用相同问题、三种教材来源、错误过滤、外部证据卡及引文评分。教材正文每个文字题最多 3,000 字符，同页三问合并最多 9,000 字符。扩大内部候选池是版本改动的一部分。

| 指标 | 旧版 | 优化二版 |
| --- | ---: | ---: |
| 候选池有完整教材证据的题 | 11/22（50.0%） | 18/22（81.8%） |
| 候选前 8 条有完整教材证据的题 | 11/22（50.0%） | 12/22（54.5%） |
| 交付段落中已确认支持本题的比例（下界） | 15/113（13.3%） | 29/131（22.1%） |
| 交付教材证据能完整回答的单问 | 11/22（50.0%） | 15/22（68.2%） |
| 同页三问合并后的教材证据覆盖 | 16/22（72.7%） | 17/22（77.3%） |
| 教材与外部资料合并后的建站要求覆盖 | 24/29（82.8%） | 25/29（86.2%） |
| 所有要求都有充分证据的页面 | 3/8 | 4/8 |

段落比例只计命中本题已核验支持引文的段落。其余段落可能包含背景、同义表达、部分证据或无关内容。完整覆盖同时核对各方法返回的等效原文，使用同一套引文标准。新增的完整页面是 MANOVA，资料包补齐了观测相互独立、协方差矩阵齐性和因变量多元正态三项假设。

逐要点原文核验已作为可选编辑入口离线复测。24 道文字题的模型核验耗时中位数约 14 秒。编辑仍逐项核查成稿，证据缺口可按字段补查原页、教材同义词或已核验的外部资料。
