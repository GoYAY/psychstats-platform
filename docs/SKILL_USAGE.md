# 单独使用自定义术语 Skill

## 获取完整包

1. 打开 [explain-research-term.zip](../downloads/explain-research-term.zip)。在 GitHub 文件页面使用下载按钮保存到本机。
2. 解压后保留 `explain-research-term` 目录及全部子目录。
3. 按所使用的 AI 工具的 Skill 安装方式，安装或加载这个目录。入口为 `SKILL.md`。

也可以从[源码目录](../term_explainer/skills/explain-research-term/)取得同样的文件。

## 它帮助你做什么？

围绕一个研究术语，明确学习目的、核对资料、阅读相关来源，并组织操作性定义、通俗解释、图示规划、公式与符号、使用方法、学术表达和理解检查。

可从这段请求开始：

> 请使用 explain-research-term 协助我理解一个术语。
>
> 术语：……
> 我希望解决的问题：……
> 我提供的资料：……
> 当前希望得到：……

材料数量与发送范围由当前任务确定。需要联网、模型调用或额外工具时，按宿主能力和当前授权执行。

## Skill 与网站生成服务

独立包包含教学规则、输出合同和辅助协议。程序化文献处理、自动绘图、任务恢复和网页交付由本项目的生成后台实现，见[运行说明](RUNNING.md)。

希望直接使用网站功能，可以进入[测试站生成入口](https://cdst.site/psy-stats-test/library/index.html#view=generate)，按页面提示使用内测邀请。
